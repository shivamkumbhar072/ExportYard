ExportYard – Complete deployment from scratch
1. Delete old deployment and clone repository
Destructive – deletes existing deployment
pm2 delete all
pm2 save --force

sudo rm -rf /var/www/ExportYard
sudo rm -f /etc/nginx/sites-enabled/exportyard
sudo rm -f /etc/nginx/sites-available/exportyard

sudo mkdir -p /var/www
sudo chown ubuntu:ubuntu /var/www

cd /var/www
git clone https://github.com/shivamkumbhar072/ExportYard.git

cd /var/www/ExportYard


2. Configure and start backend + frontend
cd /var/www/ExportYard/Backend

npm install
nano .env


Paste your actual production environment variables and save.

Then execute:
chmod 600 .env

pm2 start server.js --name exportyard-api
pm2 save

cd /var/www/ExportYard/Frontend

npm install

echo "VITE_API_URL=https://exportyard.com" > .env

npm run build


Keep a secure backup of your backend .env file. Never commit it to GitHub.
3. Configure Nginx + SSL + final verification
sudo tee /etc/nginx/sites-available/exportyard > /dev/null <<'EOF'
server {
    listen 80;
    server_name exportyard.com www.exportyard.com;

    root /var/www/ExportYard/Frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    client_max_body_size 20M;
}
EOF

sudo ln -s /etc/nginx/sites-available/exportyard /etc/nginx/sites-enabled/exportyard

sudo nginx -t && sudo systemctl reload nginx

sudo apt install certbot python3-certbot-nginx -y

sudo certbot --nginx -d exportyard.com -d www.exportyard.com

pm2 save
pm2 status
sudo systemctl status nginx
curl -I https://exportyard.com


SSL note: If Certbot says the certificate already exists, select 1 to reinstall it. If it is already correctly installed, you can skip Certbot.

Future updates (without deleting everything)
When you only change code and push it to GitHub, you don't need a fresh deployment.

Use this shorter command:
cd /var/www/ExportYard

git pull origin main

cd Backend
npm install
pm2 restart exportyard-api --update-env

cd ../Frontend
npm install
npm run build

sudo systemctl reload nginx
